# AV Player

I'm using this project to learn Odin. This project is a media player capable of
playing audio and video. Nothing to fancy, just the most popular codecs and basic
features. Will be using ffmpeg. I heard Odin has really good support for importing
C libs so this is a nice way for me to try that out too. Wanted to learn to use
the ffmpeg library anyway.

## Features

I'm using this list to track what to build next.

* [ ] AAC audio
* [ ] H.264 video
* [ ] MP4
* [ ] Play/Pause
* [ ] Replay from beginning
* [ ] Load container
